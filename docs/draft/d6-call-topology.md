## 1. 边界定义（规范性：仅此三类为真实边界，其余一切调用 = 零开销域）

| 编号 | 边界 | 定义 | 产生方式 |
|---|---|---|---|
| **B1** | ABI 声明边界 | `extern "C"` / `extern "C++"` 块内声明的函数调用（含 `@cImport` 生成项） | 源码显式声明 |
| **B2** | 动态加载边界 | L3 compat 下经 ABI 描述符加载/调用预编译 `.so` 的符号 | 链接期确定 |
| **B3** | runtime 对切换边界 | 同一镜像内 muslang-rt ↔ muslang-rt-c 的交互点（std 底层走 rt-c = D-10 的固定集合） | 编译器/标准库固定，用户不可新增 |

**推论（规范性）**：
1. 同镜像、同 runtime 内的跨 crate / 跨模块 / 泛型实例调用 = **0 开销**（允许内联消除调用本身）；
2. 用户代码**无法制造** B3 之外的隐式边界——凡出现 B1/B2 之外的序列化、拷贝、句柄转换即为**编译器 bug**（验收项 §4.3）；
3. 每个真实边界调用点 = D-4 审计清单条目（`--emit audit`）。

## 2. 开销口径（冻结：逐行可测）

| 场景 | 加载期 | 调用期 | 口径依据 |
|---|---|---|---|
| 同镜像、同 runtime（B0 零开销域） | — | **0**（可全内联至消失） | §3.7.5 |
| B1（extern ABI） | — | **一次 C ABI 调用**（≈一次函数指针调用；零序列化、零拷贝、零分配） | §3.7.5 关键澄清 |
| B2（.so 动态加载） | 符号解析 + vtable 重映射（一次性） | **0**（与 B1 同） | §3.7.5 |
| B2 镜像体积 | + ABI 描述符 | — | 预算见 §4 |
| B3（rt↔rt-c） | — | 一次 C ABI 调用（调用点集合固定，§1） | D-10 |

**承诺（冻结表述）**：**FFI 开销 = O(模块数)，不是 O(调用点数)**——符号隔离与描述符按模块/镜像边界收取一次，调用期为常数上限（一次 C ABI call）。

## 3. 编译器义务（规范性）

1. **零隐藏成本**：任何 B1/B2/B3 边界不得引入隐式拷贝、隐式分配、隐式锁、异常表或栈切换；
2. **审计完备**：`--emit audit` 列出全部边界调用点（文件/行/边界类型/D-7 策略/allocator 配对）；d4-unsafe-gate.md 的门禁据此核对"声称零开销域内的调用"未混入边界项；
3. **内联权利**：B0 域内内联不受限制；跨 B1 内联**禁止**（ABI 契约）；B2 禁止；B3 仅标准库预定义点、静态判定；
4. **布局前提**：跨界类型必须为 D-0 F 级（`E_NON_FFI_LAYOUT`），无需任何转换代码——"无转换"是 0 调用期开销的构成条件；
5. **热点钉住**：反复跨 B1/B3 的热点数据结构建议 `#[repr(C)]`（P 级，d0 §2）——文档级建议，编译器不强制。

## 4. 验收与预算

| 验收项 | 口径 |
|---|---|
| B1 调用开销 | ≤ 1 次间接 call + 参数寄存器传递（与手写 C 相同）；差分基准：同一函数 MusLang 调 vs C 调，周期差 ≤ 2% |
| B2 描述符体积 | 单模块 ≤ 2KB、单镜像总量 ≤ 16KB（⚠ 初值，M2 试点 hypo 集成时实测后冻结——超预算须拆模块而非改口径） |
| 零开销域验证 | `-Oz` 构建下，`Vec<i32>::push` 单态实例可被整体内联进调用者（`--emit asm` 抽查） |
| 隐藏成本扫描 | `--emit audit` 之外不得出现任何运行时边界跳板符号（链接期核对 muslink 符号表） |

## 5. 与既有决策的衔接

| 决策 | 衔接 |
|---|---|
| D-7 所有权移交 | B1/B2 上的 A/C 策略即边界的归属契约；B3 内部资源不跨界（rt 与 rt-c 任务队列不共享，D-19） |
| D-8 双 runtime | B3 = rt↔rt-c 唯一交互面（rt-c = std 底层 + C 互操作边界，D-10） |
| D-19 事件循环 | executor 驱动 future 属 rt 内部（B0）；`FfiFuture`（FR-044，d0 §4.6）是 B1 上驱动 MusLang future 的标准形态 |
| D-9/D-13 按需链接 + 单态化 | 零开销域的可内联性依赖单态化（HIR 层）+ section 独立 + `--gc-sections`——三层协同（§3.9.2） |
| D-4 审计 | 边界 = 审计触发器；B0 域内调用不出现在审计清单（负向测试项） |
