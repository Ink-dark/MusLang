## v0.4.6（2026-09-05）—— 自洽性修订（D-12 语义修正 + 全文传播清理）

### 核心修订

| 主题 | 内容 |
|---|---|
| **D-12 `defer` 语义修正** | `defer` 改为**全路径执行**（含 `?` 错误路径，与 Zig 一致——原文「错误路径仅 errdefer」会使 §3.2.3 示例在错误路径泄漏资源，且对 Zig `defer` 语义的引用有误）；`errdefer` 仅错误路径**补充**执行，与 `defer` 同栈 LIFO；取消（`.await` 点 drop）非错误返回，`errdefer` 不执行（§3.2.3.1、§3.7.1 D-12） |
| **D-20 对齐** | `Box` 隐式 free 依赖 defer 全路径执行 → `?` 路径不泄漏；「LIFO，先注册先执行」表述更正为「与用户 defer 同栈、按注册逆序交错执行」（§3.16.3） |
| **D-13 例外口径** | 「唯一例外」统一改为「第一（D-19 executor）/ 第二（D-20 分配器注入）」并列（§3.7.1、§3.15.7、§12.7、§15.2） |
| **D-2 传播清理** | §2 场景、§7 构建链、§6.3 CI 表、§11 风险表中的 Zig 后端残留改为 C99（MVP 默认）口径 |
| **时间线顺延** | M1 = 2026 Q4-2027 Q1、M2 = 2027 Q2-Q3、M3 = 2027 Q4-2028 Q4（原 2026 Q1-Q2 起点早于文档评审时点 2026-09-05；§8、§3.12.3、§3.13.3、§3.14.3 同步） |
| **任务模型澄清** | §3.15.2：每连接一个状态机 future（挂起不占运行槽）+ 就绪队列固定 256 深；「10 万连接」为空闲挂起口径，与 §4.1 < 500MB 衔接 |
| **其余同步** | FR-001 → 001a/001b（D-1）；FR-008 / FR-013 / FR-014（TLS 移出 P0）/ FR-047；P5「零强制运行时」（§1.2/§1.4）；§9 示例对齐 D-19（同步 main、`std::net`、Handler 统一）；§3.4.1 架构图单态化移至 HIR 层、去宏展开；§3.10.1 `longest` 改为 `E_LIFETIME_AMBIGUOUS` 报错示例；§3.11.3 改为 Itanium vtable 直接调用（去 `dyn` 表述）；§3.12.5 自举验收口径统一为 SHA-256 一致；§3.13.1 std 打包条目去自相矛盾；§4.3.1 边界检查全模式开启；§12 章首说明；仓库 URL 统一为 GitHub |

### 结构修复

- §3.16（分配器模型）由 §11 之后移至 §3.15 之后（章节归位）；
- 删除 §4 前无标题的重复性能指标孤儿表；
- 头部变更记录去重（v0.4.3 / v0.4.4 各出现两次）并修复 blockquote 断裂；
- §8 M1 表头重复、§15.2 / §15.3 表格中途断裂修复；术语表删除旧 Stage1/Stage2 条目（与 D-16 Stage 0/1/2 冲突）；

## v0.4.5（2026-09-05）—— 分配器模型定稿（D-20）

| 章节 | 决策编号 | 核心内容 |
|---|---|---|
| §3.16 分配器模型：编译期注入默认分配器 | **D-20** | **`Box::new(x)` / `Vec::new()` / `HashMap::new()` 可用**，编译器在 HIR 层自动注入默认分配器（**非 `Box<T, A>` 泛型参数、非全局可变状态**），后端只见具体调用、**不新增单态化实例**（**D-13「不引入类型擦除」的第二个例外**，与 D-19 executor 并列）；默认解析顺序 = `#[default_allocator]` 注解 > 模块级 `use as default` > 全局兜底；**`Box` / 集合作用域退出自动 free**（编译器隐式插入 `defer`，非 RAII `Drop`，与 §3.2.3 不矛盾）；**L1 core（`#![no_runtime]`）无全局兜底**，`Box::new` 报错 `E_ALLOC_NO_DEFAULT`；rt 兜底 = `GeneralPurposeAllocator`（FR-021），rt-c 兜底 = `malloc/free` via `MusAllocator::from_c`（§3.8.4，deallocator 配对）；否决 `Box<T, A>` 泛型参数方案（组合爆炸，冲击 25 层限制）；错误码 `E_ALLOC_NO_DEFAULT` / `E_ALLOC_MISMATCH` / `E_DEFAULT_ALLOCATOR_UNRESOLVED` / `W_ALLOC_LEAK`；决策表 11 项 + 实现期待办 4 项 |

## v0.4.4（2026-09-05）—— 网络运行时绑定定稿（D-19）

### 新增章节

| 章节 | 决策编号 | 核心内容 |
|---|---|---|
| §3.15 `net` 事件循环：作为 `std::net` 的依赖自动带入 | **D-19** | **事件循环（event loop / executor）是 `std::net` 的内部依赖**，随 `use std::net` 自动链接；**不提供独立的"运行时选择"**、**不引入 `#[entry]` / `block_on` 注入 API**（对标 Go，P7「网络开箱即用」）；**MVP = 单线程 epoll**（一个 loop 处理全部连接），多线程 / work-stealing = P1（FR-047），io_uring = P1；executor 内部用 **`Box<dyn Future>`**（**D-13 泛型单态化的唯一例外**，避免 `Spawn<F>` 泛型爆炸）；不用 `std::net` 时 event loop 完全不链接，`<8KB` 仍可达（D-11）；嵌入已有 C loop / 内核场景**不使用 `std::net`**、自行基于 `std::sys` + `FfiFuture`（FR-044）实现；**澄清 P5「零运行时」=「零强制运行时」**（可选、不用不链、用了也透明，§3.15.4）；决策表（11 项）+ 用户代码示例（零 boilerplate）+ 与 D-2/D-8/D-13/FR-044/D-12/D-16/D-9 衔接 + 实现期待办 4 项 |

- §15.3：追加 v0.4.4 变更行

## v0.4（2026-09-04）—— 架构决策落地（D-0 ~ D-12 决策表建立）

### 核心变更

- **定位调整**：改为「类 Rust，**不保证源码级兼容**」（§1.1，D-1）—— FR-001 拆为 001a（视觉相似）+ 001b（明确不兼容）
- **新增 §3.7 架构决策记录**：收录 D-0 ~ D-11 决策表 + 互操作架构（D-3）、共享方言 + 统一 HIR、双 runtime（D-8）、std 三层按需链接 + sys 三端可扩展（D-9/D-10）
- **默认后端**：由 Zig 改为 **C99**（FR-032、§3.4.1、§5.3，D-2）—— 理由：保证极小二进制、避免锁定未 1.0 的 Zig；LLVM = P1；Zig = P2（0.15+ 移除 async/await、`@Frame` 语义漂移）
- **`unsafe` 等价判定**（§3.2.1 K3，D-4）：禁止操作清单 + 固定错误码 + `unsafe_examples/` + `--unsafe-allowed=false` CI 门禁
- **异步模型**（§3.6.1）：改为后端无关实现，通过 `Io` 接口抽象驱动
- **二进制体积口径定稿**（§4.1、§10）：**L1 core 裸启动 < 8KB**（测量协议：`x86_64-linux-musl`、`-Oz -flto`、静态链接、无动态加载）
- **新增 M1-0 决策冻结阶段**（§8）+ v0.4 裁剪建议

### 同步修改

- §3.4.1 编译器架构图更新（C99 为默认后端）
- §5.3 后端映射调整（C99 为主路径）
- §15.3：追加 v0.4 变更行
